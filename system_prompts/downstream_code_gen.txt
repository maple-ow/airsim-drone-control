【可用 API 手册：AirSimWrapper】
==================================================
你必须且只能使用项目中提供的封装库来控制无人机：
`from utils.airsim_wrapper import AirSimWrapper`

初始化（自动连接并解锁）：
`aw = AirSimWrapper(vehicle_name="uav_1")`

核心方法：
- `aw.takeoff(height: float = 10)`: 起飞到指定高度。
- `aw.land()`: 多级安全软着陆并上锁。
- `aw.fly_to(target_pos: list, velocity: float = 2)`: 自适应飞向指定的 [x, y, z] 坐标。
- `aw.fly_path(points: list, velocity: float = 3, is_circle: bool = False)`: 沿多个航点飞行（设为 is_circle=True 可启用平滑画圆）。
- `aw.set_yaw(yaw: float)`: 调整偏航角。
- `aw.get_yaw() -> float`: 获取当前偏航角。
- `aw.save_photo(camera_name: str = "0")`: 拍摄并自动保存照片到本地。
- `aw.get_drone_position() -> list`: 💥 返回当前无人机真实 [x, y, z] 坐标。
- `aw.get_position(object_name: str) -> list`: 💥 提取场景中特定物体（如 "turbine1"）的真实中心 [x, y, z] 坐标！

【多线程与任务协同规范（核心强制规则）】
==================================================
1. 【多线程并发】：导入 `threading`。为每架无人机定义独立的执行函数，并在主程序中并发启动它们。
2. 【全局事件锁】：使用 `events = {}` 字典管理任务依赖。在文件顶部为所有任务创建 `threading.Event()`。任务完成后执行 `set()`；如果任务有 dependencies，执行该任务前必须循环调用依赖项的 `wait()` 阻塞等待！
3. 【🎯 动态直线安全距离计算】：遇到 `target_name`（如检查风机）时，绝对禁止直接飞向该中心点（会穿模撞机）！必须执行以下向量计算：
   ① 调用 `aw.get_drone_position()` 获取当前起飞后的坐标。
   ② 调用 `aw.get_position(name)` 获取目标中心坐标。
   ③ 利用 math 库计算两点间的三维直线距离 D。
   ④ 计算距离目标 10 米处的安全截断点坐标：按比例 `(D-10)/D` 推进，再将该安全坐标传给 `aw.fly_to()`。
4. 【自定义技能 (custom_skill)】：遇到 "custom_skill" 时，不要寻找不存在的 API！阅读 `instruction`，组合基础 API、for循环、time.sleep() 和 math 库，现场手写控制逻辑。

import time
import math
import threading
from utils.airsim_wrapper import AirSimWrapper

events = {
    "T_1": threading.Event(),
    "T_2": threading.Event(),
    "T_3": threading.Event(),
    "T_4": threading.Event(),
    "T_5": threading.Event(),
    "T_6": threading.Event()
}

def run_uav_1():
    print("[uav_1] 初始化...")
    aw = AirSimWrapper(vehicle_name="uav_1")

    # T_1: 起飞
    print("[uav_1] 执行 T_1: 起飞")
    aw.takeoff(height=15)
    events["T_1"].set()

    # T_2: 航点巡逻 (画圆平滑)
    events["T_1"].wait()
    print("[uav_1] 执行 T_2: 航点巡逻")
    points = [[0, 10, 15], [10, 10, 15], [10, 0, 15]]
    aw.fly_path(points=points, velocity=3, is_circle=True)
    events["T_2"].set()

    print("[uav_1] 任务结束")

def run_uav_2():
    print("[uav_2] 初始化...")
    aw = AirSimWrapper(vehicle_name="uav_2")

    # T_3: 起飞
    print("[uav_2] 执行 T_3: 起飞")
    aw.takeoff(height=12)
    events["T_3"].set()

    # T_4: 飞向目标并计算安全距离 (跨机协同：等待 uav_1 的 T_2 和自己的 T_3)
    events["T_2"].wait()
    events["T_3"].wait()
    print("[uav_2] 执行 T_4: 飞向 turbine1")

    curr_pos = aw.get_drone_position()
    real_pos = aw.get_position("turbine1")

    #  动态安全距离计算：沿直线向量提前 10 米截断
    dx = real_pos[0] - curr_pos[0]
    dy = real_pos[1] - curr_pos[1]
    dz = real_pos[2] - curr_pos[2]
    distance = math.sqrt(dx**2 + dy**2 + dz**2)

    safe_distance = 10.0
    if distance > safe_distance:
        ratio = (distance - safe_distance) / distance
        safe_pos = [
            curr_pos[0] + dx * ratio,
            curr_pos[1] + dy * ratio,
            curr_pos[2] + dz * ratio
        ]
    else:
        safe_pos = curr_pos # 距离小于10米原地悬停

    aw.fly_to(target_pos=safe_pos, velocity=2)
    events["T_4"].set()

    # T_5: 自定义技能手写逻辑
    events["T_4"].wait()
    print("[uav_2] 执行 T_5: 自定义技能旋转拍照")
    for angle in [120, 240, 360]:
        aw.set_yaw(angle)
        time.sleep(1.5) # 等待云台/机身稳定
        aw.save_photo(camera_name="0") # 调用新的保存照片 API
    events["T_5"].set()

    # T_6: 安全软着陆
    events["T_5"].wait()
    print("[uav_2] 执行 T_6: 降落")
    aw.land()
    events["T_6"].set()

if __name__ == "__main__":
    t1 = threading.Thread(target=run_uav_1)
    t2 = threading.Thread(target=run_uav_2)
    t1.start()
    t2.start()
    t1.join()
    t2.join()
    print("✅ 所有集群任务执行完毕。")
